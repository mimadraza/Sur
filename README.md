🎵 Sur – Spotify Replica

Sur is a Spotify-inspired web application designed to give users and artists a sleek and modern music experience.
It features an elegant UI, user authentication, and a responsive layout for exploring and managing music.

🚀 Features
🖤 Authentication

Create an account or log in securely.

Choose between Artist and User roles during sign-up.

Password and input validation for enhanced security.

🎧 Music Library

User Dashboard with personalized music recommendations.

Your Library for saved and liked tracks.

Made For You section for automatic playlists.

Functional music player with playback controls.

🌈 Interface

Gradient-themed modern UI.

Fully responsive design for different screen sizes.

Smooth navigation between login, register, and dashboard pages.
